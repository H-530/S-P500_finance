# 📊 S&P 500 Financial & ESG Data API

A developer-friendly tool for extracting structured financial, sustainability, and company data from S&P 500 companies.

This project simplifies the process of collecting historical financial statements, financial ratios, ESG scores, peer-group sustainability data, and S&P 500 company tickers for financial analysis, research, and data-driven applications.

## ✨ Features

### 💰 Financial Data

Extract historical quarterly financial data for S&P 500 companies, including:

- 📑 Balance sheets
- 💸 Cash flow statements
- 📊 Financial ratios
- 💰 Dividends
- 📈 Other financial metrics provided by the data source

Financial data can be exported to CSV files for further analysis, visualization, or integration into other applications.

### 🌱 ESG & Sustainability Data

Extract historical sustainability data for S&P 500 companies, including:

- 🌍 Company ESG scores
- 👥 Peer-group ESG scores
- 📅 Historical monthly ESG data

ESG data can be exported to CSV files for analysis and comparison.

### 🏢 S&P 500 Company Tickers

Retrieve the current list of S&P 500 companies and their stock tickers.

The resulting dataset is stored as a JSON file and can be used as the foundation for subsequent financial and ESG data extraction.
